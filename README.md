# ML_Final_Group5

Final Project for UchiADS ML2.

## Purpose
Build a reliable traffic sign recognition system using preprocessed image data to demonstrate practical computer vision modeling and deployment readiness.

## Method
- **Data**: Preprocessed traffic sign images from the Kaggle dataset.
- **Approach**: Train and evaluate supervised classification models to recognize traffic sign categories, with performance measured via standard classification metrics.
- **Tools**: Python-based ML stack (e.g., NumPy, pandas, scikit-learn, and deep learning libraries) for data preparation, modeling, and evaluation.

## Business Sense
Accurate traffic sign recognition enables safer driver-assistance systems, supports autonomous vehicle perception, and reduces the risk of costly accidents or compliance failures. This project showcases an end-to-end ML workflow that can translate into production-ready computer vision capabilities.

Data source: https://www.kaggle.com/datasets/valentynsichkar/traffic-signs-preprocessed/data
